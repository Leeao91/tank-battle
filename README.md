# 坦克大战 · Tank Battle

一个用原生 HTML + Canvas + JavaScript 编写的经典《坦克大战》(Battle City) 网页版游戏，**单文件、零依赖**，打开即玩。

## 🎮 玩法

- 控制你的坦克，**保护下方的基地（鹰徽）不被敌军击毁**
- 消灭关卡内所有敌军即可过关，逐关推进
- 砖墙可被击毁、钢墙需火力强化才能击穿、水面挡住坦克但挡不住子弹、草丛会隐藏坦克

## 🕹️ 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 或 `W` `A` `S` `D` |
| 射击 | `空格` 或 `J` |
| 暂停 / 继续 | `P` |
| 开始 / 重新开始 | `空格` |

> 移动端（手机/平板）会自动显示屏幕虚拟按键。

## ✨ 特性

- 3 种地图 + 无限关卡（难度递增）
- 4 种敌军：普通、快速、火力、装甲（4 滴血）
- 6 种道具：⭐火力升级、🛡防护罩、🧱基地钢化、❤额外生命、💣全屏清敌、⏸时间冻结
- 经典得分系统与最高分记录、3 条生命、基地鹰徽
- 粒子爆炸特效 + Web Audio 音效
- 桌面键盘与移动端触屏双操作

## 🚀 运行

方式一：直接用浏览器打开 `index.html` 即可。

方式二：本地起一个静态服务器（可选）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
